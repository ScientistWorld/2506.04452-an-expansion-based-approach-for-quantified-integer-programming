# Experiment Overview

## qrandomparity_n100
This experiment checks how quickly a solver handles the reproduced large-instance
QRandomParity setting while still producing decisive answers across the full
evaluated instance set.

## Reference-Only Context

The paper also reports a harder `qrandomparity_n200` setting. It remains in
`scoring/reference.json` for context, but it is not part of the current reproduced
baseline until matching entries appear in `scoring/scores.json`.
